# 写一个程序监控新增进程
## 扫描发现新增的进程
## 记录进程的信息
- 线程数
- 句柄数
- 内存占用量
- cpu时间
- 进程运行时间
## 信息生成到xlsx
- 信息的最小值
- 信息的最大值
- 信息的最新值
## 用python完成程序

## 使用方式

程序文件：`aliyunlog/code/process_monitor.py`

安装依赖：

```bash
pip install -r requirements.txt
```

启动监控新增进程，按 Ctrl+C 停止并生成 xlsx：

```bash
python aliyunlog/code/process_monitor.py --interval 2 --output aliyunlog/output/process_monitor.xlsx
```

只运行 60 秒后自动生成 xlsx：

```bash
python aliyunlog/code/process_monitor.py --duration 60 --output aliyunlog/output/process_monitor.xlsx
```

默认只监控程序启动后新增的进程；如果要把启动时已经存在的进程也纳入统计，增加 `--include-existing`。

xlsx 包含两个工作表：

- `summary`：每个进程的线程数、句柄数、内存占用、CPU 时间、运行时间的最小值、最大值、最新值。
- `samples`：每次采样的原始明细。
